MoonTrainer 中文使用说明
========================

MoonTrainer 是 Moon Sweepers 的钱包修改器，只改存档里的团队钱包金额；不改游戏程序，不需要联网，也不需要安装 Node.js 或 .NET。

可以修改：
  团队钱包金额

只读查看：
  钱包、容器条目数、升级树节点数

不会修改：
  容器等级、升级树等级、工具/车辆的购买状态、成就、地形、物品、任务进度


一、运行前
----------
1. 先退出游戏，回到桌面。游戏运行时工具会拒绝写入。
2. 建议先手动备份整个存档文件夹，尤其是开了 Steam 云同步的情况。
3. 本工具是 Windows x64 程序，不需要安装 Node.js 或 .NET。
4. 第一次运行如果 Windows 提示“未知发布者”，这是本地打包的 exe 签名失效所致；
   确认文件来自你自己的 MoonTrainer 文件夹后，选择“更多信息 → 仍要运行”。


二、最简单的用法（双击）
------------------------
1. 双击 MoonTrainer.exe。
2. 工具会自动列出所有存档，例如：
     slot-1  world e42ac78bf8be  wallet $1000  tree nodes 5
3. 如果有多个存档，按提示输入序号；只有一个时直接进入金额输入。
4. 输入新的钱包金额，直接回车则使用默认值 1000000。
5. 输入 y 确认写入。
6. 看到 OK 后关闭窗口，启动游戏并读取对应存档。

注意：钱包是团队共享的，联机时队友也会看到修改后的金额。


三、命令行用法
--------------
在 MoonTrainer 文件夹打开终端（在地址栏输入 cmd 回车），然后运行：

  MoonTrainer.exe
      交互模式，等同于双击。

  MoonTrainer.exe list
      列出所有存档、钱包、升级树节点数和修改时间。

  MoonTrainer.exe show
      显示当前存档的钱包和只读信息。
      只有一个存档时可直接用；多个存档时加 --slot N 或 --file。

  MoonTrainer.exe show --slot 1
  MoonTrainer.exe show --file "完整路径\session.moon"
      指定存档查看。

  MoonTrainer.exe set-money 1000000 --yes
      把团队钱包设为 1,000,000。

  MoonTrainer.exe add-money 50000 --yes
      在现有钱包基础上加 50,000。

常用参数：
  --slot N        指定存档槽位，例如 --slot 1
  --file PATH     直接指定 session.moon 的完整路径
  --yes           确认写入；命令行修改必须加，否则只显示计划不写入

金额写法：
  1000000      整数可以直接写
  1234.56      支持小数
  $1,000,000   美元符号和逗号会自动忽略
  负数不允许


四、存档位置与备份
------------------
默认存档根目录：

  %USERPROFILE%\AppData\LocalLow\DragDropGames\MoonSweepers\MoonSessions

每个存档类似：

  ...\MoonSessions\slot-1\<世界哈希>\session.moon

工具会自动查找 slot-* 下的 session.moon。

每次写入前，会在 session.moon 同目录生成：

  session.moon.trainer-backup-年月日时分秒毫秒

写入后会重新读取并校验：
  - 文件头和 SHA256
  - 钱包金额
  - 除钱包字段外的其余存档字节未改变

任何一步失败，会自动把原文件恢复。备份文件不会自动删除，确认无误后可手动清理。


五、常见问题
------------
Q: 提示 Moon Sweepers is running.
A: 游戏还在运行。请完全退出到桌面后再运行。

Q: 提示 no save found.
A: 没有找到存档。先启动游戏并创建一个存档，再退出游戏重试。

Q: 提示 multiple saves.
A: 有多个存档。命令行加 --slot 1 或 --file "完整路径" 指定一个；
   双击运行时按提示输入序号即可。

Q: 主菜单显示的钱还是旧的.
A: 主菜单的摘要来自 slot.json，下次游戏保存时会更新；实际钱包以进入游戏后为准。

Q: show 里的 Read-only 是什么.
A: 只读显示容器条目数和升级树节点数，不会修改它们。

Q: 会不会修改容器和升级树等级.
A: 不会。本工具只写钱包；写入后会把除钱包外的所有字节逐字节比对，必须完全一致。

Q: 游戏里已有的高级/满级升级会被重置吗.
A: 不会。本工具不碰这些数据。

Q: 会不会影响联机队友.
A: 会。钱包是共享的，队友会看到修改后的金额。请只在单人模式或征得队友同意后使用。

Q: 会不会被封号.
A: 本工具只改本地存档，不注入游戏、不改游戏程序、不绕过 Steam。
   但联机修改共享进度属于作弊行为，请自行判断使用场景。

Q: 能不能解锁全部工具和车辆.
A: 不能。本工具只改钱包；工具和车辆需要你在游戏里用修改后的钱购买。

Q: 想改容器或升级树等级.
A: 本工具不提供等级修改，只改钱包。

Q: 想恢复原样.
A: 把同目录下最新的 session.moon.trainer-backup-... 复制回 session.moon 即可。
   复制前先退出游戏。


六、卸载
--------
删除整个 MoonTrainer 文件夹即可。工具不写注册表，也不改游戏安装目录。
存档目录里的 trainer-backup 备份按需删除。
